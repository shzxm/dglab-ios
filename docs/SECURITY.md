# 安全说明 / Security

## 凭证保护

- iOS 不需要 Telegram Bot Token；仅使用高熵、单独配置的 `IOS_BRIDGE_TOKEN`，由 Keychain 保存。
- 在外网只使用加密 `wss://` 和可信认证网关；本机或可信私有网络内使用 `ws://`，不要公开暴露桥接端口。
- 私人桥接地址仅存本地用户设置。源码、Issues、截图和日志中不得出现实际 Token、内部 IP、私人聊天 ID、证书或用户资料。
- 桥接密钥属于管理员级别凭证；若泄露应立即在 Mac 端轮换。

## 实体设备警告

- 本项目是实验性质的第三方开发工具，不是医疗设备或安全保证系统。
- `133` 为程序取值上限，**不是安全的电流/身体承受等级**。A/B 初始上限为 0，必须在设备旁明确设置和授权。
- 音量/节拍波形调制可与自动提升同时进行，复合变化可能更难预测。
- App 退后台、蓝牙中断、WebSocket 失联、系统终止时只能**尝试**发送停止/归零，不能保证蓝牙数据包最终抵达设备。使用者必须拥有独立、立即可用的物理断开手段。
- 未经真实设备的完整 BLE、授权和失败路径验收，不应把模拟器/单元测试的结果当作实际安全验证。

## 上报漏洞

公开 Issue 只适合无敏感信息的最小重现。可能引发未经授权设备控制、凭证泄露或安全停止失败的问题，请先通过仓库的私密漏洞报告（若已启用）报告，或联系仓库维护者，不要在公开问题中贴密钥。
